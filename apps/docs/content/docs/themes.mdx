HowlBox has 31 themes across four families. Each theme defines its own typography, surfaces, borders, and shadows. The overlay loads only the CSS for the selected theme.

Open the [configurator](/config/) to see the live preview and select a theme. The [landing page](/#themes) shows the theme wall.

## Color variants

Variants change a theme's palette while keeping its layout and typography. Add `variant` to the URL only for a theme that supports it:

```text
/overlay?channel=you&theme=terminal&variant=amber
```

Available variants are `terminal` (`amber`, `ice`), `neon` (`cyan`, `lime`), `cozy` (`mint`, `peach`), `galaxy` (`nebula`), `gameboy` (`pocket`, `virtual`), `cyber` (`gold`), `ember` (`coal`), `ocean` (`tropic`), and `luxe` (`silver`, `rose`). Unknown values use the theme's default palette.

## Display modes

Every theme supports the three background modes:

- `bg=off` keeps the page transparent and outlines text for contrast.
- `bg=panel` draws one themed surface while messages are present.
- `bg=bubble` draws a surface behind each message.

Reduced-transparency settings switch surfaces to opaque colors. Reduced-motion settings disable ticker motion and animated art.
