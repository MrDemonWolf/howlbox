## Build an overlay URL

The [configurator](/config/) keeps the overlay visible while you choose its theme, layout, and chat options. Paste an older GitHub Pages overlay URL into the builder and it will load those settings into the current URL format.

<Callout type="info">
  HowlBox connects to Twitch chat anonymously. It does not need an account, OAuth token, API key, or backend.
</Callout>

## What the overlay can do

- Show Twitch chat with native Twitch, 7TV, BTTV, and FrankerFaceZ emotes.
- Render channel badges, custom badge art, and the MrDemonWolf owner badge.
- Choose from 31 themes, three background modes, and optional event rows.
- Configure filters, message timing, emote size, avatars, and pronouns in the URL.

## What it cannot do

The connection is read-only. It cannot send or moderate chat, read deleted message contents or the mod queue, load chat history from before it connected, or show follower alerts. See [anonymous chat limits](./limitations) for details.
